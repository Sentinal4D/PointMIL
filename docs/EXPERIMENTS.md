# Experiments: config to paper mapping

Every YAML under `configs/` is one experiment with all hyperparameters written out.
The files are generated by `scripts/make_configs.py`; the values come from the
training arguments stored in the original checkpoints, the W&B configs and the
OpenPoints yaml files of the runs behind the paper.
`experiment.recipe` says which of the two original code paths an experiment
followed:

* `pointmil`: the original PointMIL code (Lightning). AdamW or SGD, plain
  cross-entropy, cosine schedule, checkpoint selection on the validation F1
  (or accuracy), random point subsampling, unit-ball normalisation, anisotropic
  scale and shift augmentation, xyz plus normals as input where normals exist.
* `openpoints`: the PointNeXt training strategy (Qian et al., NeurIPS 2022) as implemented in the
  OpenPoints library and run through the authors' fork of it (ATLAS-1, ScanObjectNN, PointMLPElite on
  IntrA and RBC). SGD (ATLAS-1, IntrA, RBC) or AdamW (ScanObjectNN), no weight decay on
  biases and normalisation weights (`optimizer.filter_bias_and_bn`, the OpenPoints
  default), cross-entropy with label smoothing, cosine schedule stepped once per epoch,
  gradient clipping, checkpoint selection on overall accuracy, separate MIL head
  (`pointmil.pooling.OpenPointsMILHead`). ScanObjectNN uses the OpenPoints transforms
  (point shuffling, scaling, centring with a height channel, rotation); ATLAS-1, IntrA
  and RBC use no augmentation, because the fork's loaders for these datasets do not
  apply the transforms named in their run configs.

Run any experiment with

```bash
python scripts/train.py --config <yaml> --fold <k> --seed 42 --data_root $POINTMIL_DATA
```

(`--fold` for IntrA and RBC only). Checkpoints, `log.csv` and `summary.json` land in
`outputs/<experiment.name>/fold<k>_seed<seed>/` (`seed<seed>/` for the single-split
datasets).

## Checkpoint selection

`train.val_split` sets the split used for checkpoint selection and early stopping:
`test` (the provided configs), `validation` (the validation subset of ATLAS-1) or
`holdout` (a stratified subset carved out of the training folds). `summary.json` reports
the test metrics of the selected and of the last checkpoint and the best validation
values reached during training.

## Fig. 7 and Supplementary Fig. 12: robustness to noise

`scripts/noise_robustness.py` adds Gaussian noise to a growing number of randomly
chosen points of the test clouds and reports F1 and mACC (Supp. Fig. 12 used the
DGCNN backbone on IntrA: `configs/table1/intra_dgcnn_*.yaml`; Fig. 7 shows the
ModelNet40 Transformer interpretations under added noise, which
`scripts/interpret.py importance` produces for noisy inputs).

## Training details

| Setting | pointmil recipe (IntrA, RBC) | pointmil recipe (ModelNet40) | openpoints recipe (ATLAS-1) | openpoints recipe (ScanObjectNN) |
|---|---|---|---|---|
| Optimiser | AdamW, lr 1e-3, wd 1e-4 | SGD, lr 0.1, momentum 0.9, wd 1e-4 | SGD, lr 0.1, momentum 0.9, wd 2e-4 (not on biases and norm weights) | AdamW, lr 2e-3, wd 0.05 (not on biases and norm weights) |
| Schedule | cosine to 1e-6 over all epochs | cosine to 1e-3 | cosine to 5e-3 over 100 epochs | cosine to 1e-4 over 200 of 250 epochs |
| Epochs | 250 (300 for the k sweep, CurveNet and the Transformer CLAIM baseline) | 200 (Transformer), 250 (DGCNN, PointNet) | 100 | 250 |
| Batch size | 8 (RBC Transformer: 16) | 32 | 16 (PointMLP: 8) | 32 (Transformer 4, PointMLP 8) |
| Loss | cross-entropy | cross-entropy | cross-entropy, label smoothing 0.2 | label smoothing 0.3 |
| Points | 1024 random of the file (IntrA: xyz + normals; RBC: xyz + normals for the Transformer, xyz otherwise) | first 1024 of 2048 (xyz) | 1024 by FPS from 4096 (xyz) | first 1024 of 2048, shuffled, in training; FPS 1024 at test (xyz + height) |
| Augmentation | anisotropic scale U(0.8, 1.2), shift U(-0.2, 0.2) | scale U(2/3, 3/2), shift U(-0.2, 0.2), shuffle | none | scale U(0.9, 1.1), y-axis rotation, centring |
| Model selection | best val F1 | best val accuracy | best val accuracy | best val accuracy |
| Transformer | k-NN 32 and 64, channels 128 and 256, query MLP 64 and 256, d_k 32, 8 heads, d_v 16 and 32 | same with k-NN 20 and 20 | same as IntrA, xyz only | same, xyz + height (4 channels) |
| Pooling heads | IntrA: linear classifiers, dropout 0.1; RBC: non-linear classifiers (dropout 0.1 Transformer, 0.5 PointNet and DGCNN); sinusoidal positional encoding, contextual attention k = 12 | non-linear classifier, dropout 0.5, no positional encoding | OpenPoints head, dropout 0.5 | OpenPoints head (MLP variant for Transformer and DGCNN) |
| Seed | 42 | 42 | 42 | random (recorded in run names) |
